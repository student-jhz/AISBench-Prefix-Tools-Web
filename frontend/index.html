输入远程执行机的 SSH 连接信息（服务部署于本机时，可连接宿主机或任意远程机器）

💡 提示

计算公式

              
并发数 = floor( total_kv_cache / (input_len + output_len) )

              
最小请求数 = floor(total_kv_cache / input_len / repeat_rate) + 1

              
推荐请求数 = 最小请求数 × 2

              
KV使用率 = 并发数 × (input_len + output_len) / total_kv_cache × 100%
